# Fabrication Prevention Checklist

Use this checklist to validate resume/cover letter content before finalizing.

## ❌ Common Fabrications to Avoid

### Industry Context Fabrication
- [ ] Converting "scheduling application" → "healthcare scheduling" 
- [ ] Converting "data reconciliation" → "patient data reconciliation"
- [ ] Adding "HIPAA compliant" when not explicitly documented
- [ ] Assuming generic systems are domain-specific

### Client Details Fabrication  
- [ ] Adding specific patient counts (e.g., "50,000+ patients")
- [ ] Adding specific facility types (e.g., "NJ mental health facilities") 
- [ ] Inventing client industries not documented
- [ ] Adding geographic details not stated

### Scope Inflation
- [ ] Converting "contributed to" → "led" 
- [ ] Adding team sizes not documented
- [ ] Inflating metrics or timelines
- [ ] Claiming ownership of collaborative work

### Technology Claims
- [ ] Adding technologies not listed in experience.json
- [ ] Claiming expertise in tools only mentioned briefly
- [ ] Upgrading familiarity to expertise

## ✅ Validation Questions

Before finalizing, ask:

1. **Is this claim explicitly in experience.json?** If not, remove it.
2. **Am I inferring industry context?** Stick to documented facts.
3. **Am I adding client specifics?** Only use what's documented.  
4. **Am I claiming skills not proven?** Every skill must have documented usage.
5. **Are my metrics exact?** Don't round up or extrapolate.

## Real Example: JudiHealth Fabrication

❌ **FABRICATED**: 
"healthcare data reconciliation, solving client inability to reconcile patient data between multiple vendor systems and improving care coordination for 50,000+ patients"

✅ **TRUTHFUL**: 
"data reconciliation, solving client inability to reconcile inventory between vendors, partners, and internal systems"

**The difference**: Adding "healthcare", "patient data", "care coordination", and "50,000+ patients" when the source only mentions "inventory reconciliation" between systems.
